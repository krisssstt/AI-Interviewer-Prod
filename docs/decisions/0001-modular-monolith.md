# ADR-0001: модульный монолит и постепенная миграция

Контекст: статический UI с полезными стилями и локальными сценариями; backend отсутствует.

Варианты: переписать SPA; оставить локальную оценку; сохранить HTML и добавить сервер.

Решение: FastAPI/Pydantic/SQLAlchemy/Alembic, тот же origin для UI и API. Модули identity, competencies, training, learning; knowledge/assessment добавляются при реализации. Правила отдельно от HTTP. Без универсальных репозиториев и пустых модулей. Зависимости фиксируются lock-файлами.

Последствия: дизайн сохраняется; на перенесённых страницах старые скрипты не запускаются. Сервер не отдаёт legacy-банк ответов. Неперенесённые функции явно недоступны в серверном режиме, оригинальный UI остаётся отдельным прототипом.
